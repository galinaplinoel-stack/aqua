Why AQUA?

Everything you need to build and manage AI agent teams.

🤖

Multi-Agent Hierarchy

Define departments, roles, and org charts. Spawn specialized sub-agents and delegate tasks autonomously.

🔧

80+ Built-in Tools

Web scraping, code execution, database queries, file management, VPS control, and more — all ready to use.

🎭

Customizable Persona

Edit a simple markdown file to define your agent's personality, rules, and behavior. No code changes needed.

💾

Persistent Memory

Your agent remembers context, facts, and conversations across sessions. Search and manage memories easily.

🖥️

Full VPS Management

System info, process management, firewall rules, Docker, cron jobs, and package installation — all from chat.

📱

Platform Integration

Connect to Telegram and other messaging platforms. Chat with your agents from anywhere.
